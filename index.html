同样叫管家婆，V1 和 A8 差着好几个量级。点击下方标签，逐个系列看核心功能、版本差异、适用人群与典型场景。

⚙️核心功能

  • 傻瓜式进销存：采购、销售、入库、出库单据录入，系统自动分类汇总
  • 自动财务：进销存账、库存明细、应收应付自动生成，不懂会计也能管
  • 多价格体系：客户分级价、预设售价、促销价，适配工程分批送货
  • 库存预警 + 账龄分析：效期提醒、呆滞报警、应收账龄一屏看清
  • 多端协同：云辉煌支持电脑 / 手机 / PDA，业务员外勤开单

👥适合谁用

  • 五金批零、电脑数码、手机通讯、日用百货等单店或小型批零企业
  • 核心诉求："把货记清、把钱对上"，没有专职会计
  • 从手工记账 / Excel 台账转向数字化的第一步
  • 预算敏感、追求当天上手当天见效的老板

💡选型提示

如果你的行业有明显的"非标"特征——必须管颜色尺码、必须管保质期、必须管批次追溯、必须按米按卷核算——请直接跳过通用版，选对应行业专版。行业版已把行业惯例做进底层逻辑，能省去大量二次开发成本和操作麻烦，员工也不用改习惯去迁就软件。

⚙️核心功能

  • 网上管家婆·云进销存：线下批发企业采–销–存–财一体
  • 网上管家婆·云供应链：多门店多仓库，线上线下批发 + 少量零售
  • 网上管家婆·网店ERP：多平台多网店订单、库存同步、对账（对接 100+ 电商/物流/仓储平台）
  • iShop：基于 SaaS+BI+AI 的新一代 ERP，电脑/手机/iPad/PDA/POS 多端协同，对接电商与微商城
  • 熊掌柜：夫妻店、移动摊位的极简开单收银，数据同步上云

👥适合谁用

  • 不想买服务器、不想养运维的轻资产商户
  • 老板要随时看数、店员要移动开单的零售团队
  • 多平台开店的电商卖家（淘宝/京东/拼多多/抖音/快手）
  • 想把微商城 / 线上订货慢慢接进来的成长型商户

💡生态的真正价值

单款软件只是底座，管家婆的延展性在"周边那一圈"：管账 → 管业务 → 管渠道 → 管门店 → 管资金。选型时先跑通主系统，哪个环节最痛就补哪个模块，像搭积木一样按需拼装，不必一次性为用不上的功能买单。

Problems Solved

能解决什么问题：老板们的 8 大"心头病"

管家婆融合 80 万+ 企业最佳实践，每一个功能都对着一个真实的经营痛点。

?账实不符：系统有账、仓库没货
采购、销售、调拨、盘点全流程入系统，库存数据实时更新；配 WMS + PDA 扫码作业后，账实相符率可达 99%+，彻底告别"凭记忆找货"。
?糊涂账：赚了赔了全靠年底感觉
业务单据自动生成财务凭证，利润表、资产负债表自动出具；往来账龄、费用分摊一屏看清，每天都能看到真实利润。
?赊销失控：欠款越拖越久、坏账频发
客户信用额度自动控制，超限不让开单；账龄分析自动分级预警，谁该催款、催多少一目了然，把坏账挡在发生前。
?多店多仓：各干各的、总部看不清
总-分-门店多机构一套系统，库存实时同步、统一采购调拨、价格体系隔离管控；老板手机上就能看全部门店经营数据。
?生产黑箱：缺件停产、进度靠吼
BOM + MRP 运算提前算好该采什么、投产多少；工单下到车间、工序报工扫码完成、进度看板实时可见，把"缺件与超储"这对老矛盾一次理顺。
?成本算不清：卖了货不知道赚没赚
料工费自动归集到每个产品、每张工单，可追溯到最细的成本明细；哪款产品真赚钱、哪款在亏钱，数据说了算。
?电商超卖漏发：多平台手工录单到半夜
对接 100+ 电商/物流/仓储平台，订单自动下载、智能审单、合并拆分、批量打单；线上线下库存实时同步，从源头杜绝超卖。
?合规风险：药监检查、食品追溯不过关
千方百剂内置 GSP 合规流程；食品版批次效期预警保障可追溯；UDI 一物一码溯源。让合规成为日常动作，而不是检查前的手忙脚乱。
Cost Savings

能节约什么成本：省出来的都是净利润

软件费是明处的几千块，省下来的是暗处的几十万。以下为管家婆客户实践中的典型收益区间。

🧾对账 / 录单人力成本
对账时间 -70% · 约省 0.5-1 人
单据自动生成凭证、往来自动对账，会计和录单员从"搬运数字"里解放出来。按人均 6-10 万/年计，一年即回本多年软件费。
📦库存资金占用
库存周转 +45% · 呆滞资金释放
库存预警 + 效期预警 + 呆滞分析，缺货自动提醒补、滞销及时清。积压的每一件货，都是压在账上的现金。
💸报损与坏账损失
损耗显著下降 · 坏账前置拦截
食品/药品效期预警减少过期报损；客户信用额度 + 账龄预警把坏账拦截在开单之前。这类"看不见的漏水"最伤利润。
🏭生产隐性浪费
缺件停产减少 · 用料更精准
MRP 算料替代"老师傅拍脑袋"，多采变少采、漏采变及时采；工序报工让车间效率透明化，减少窝工待料。
🤝采购与沟通成本
流程自动化 · 扯皮变数据
采购订单、审批流、内部调拨线上化，业务、仓库、财务共享同一套数据，"签了单没货""发了货没记账"的扯皮大幅减少。
🖥️IT 建设与维护成本
云版免服务器 · 免专职运维
云端部署无需自购服务器、无需专职网管，数据云端存储 + 银行级备份机制，小微企业也能享受企业级安全。

3-Step Selection

三步锁定你的那一款

选型前只需回答三个问题：多大规模、有没有生产、要不要上云。三个维度定下来，往里套，基本不会偏。

第一步：看规模

单店 / 小批零，还是多门店、多分支、集团化？这决定了产品的组织架构能力上限。

单店 → 辉煌 / 熊掌柜多店 → 分销V3集团 → A8 / 天通S3

第二步：看有没有生产

只管贸易往来，还是要管车间、BOM、工序、成本？有没有委外加工？

纯贸易 → 财贸简单加工 → Q5工厂 → 工贸T系 / M系

第三步：看要不要上云

愿意自己搭服务器、要数据本地掌控？还是想免运维、手机随时开单看报表？

本地 → 买断版上云 → iShop / 云系列电商 → 网店ERP
FAQ

常见问题

入门产品如易指开单约 680 元/年、熊掌柜约 580 元/用户/年、云辉煌约 880 元/年起；财贸本地买断低至 1,280 起、云端 1,880 起；工贸云版约 4,000/年起；分销 ERP、A8 等按版本与用户数报价。报价差异主要来自版本型号、用户数、买断还是年费、是否含实施培训，以及不同服务商的服务包。建议以"3 年总成本（用户数 × 年费 × 年限，或买断价 + 维护费）"来横向比较。
买断版：数据本地、一次付费长期使用，适合有 IT 基础、注重数据物理掌控、计划用 5 年以上的企业。云版：免服务器免运维、按年付费门槛低、多端协同方便，适合没有网管、想快速上线、经常需要移动办公的团队。管家婆两条路线都有，可随企业发展平滑迁移。
这正是管家婆辉煌系的设计初衷——"傻瓜式进销存 + 自动财务"：录入采购/销售单据后，系统自动分类汇总，进销存账、库存明细、应收应付自动生成，不需要懂会计分录。当然，若需要出标准三表二账做报税，可升级到财贸双全，让专职会计来做专业的事。
不需要推倒重来。管家婆产品线本身设计了成长阶梯：熊掌柜 / 易指开单 → 辉煌 / 云辉煌 → 财贸双全 → 分销 ERP V3 → 分销 A8 / 天通 S3 → 工贸 T9。同一套数据理念一路升级，历史数据可迁移，避免"长大即换系统"的沉没成本。
可以。网店 ERP 与全渠道连接器负责对接淘宝、京东、拼多多、抖音、快手等平台的订单、库存、商品信息实时同步；订货易 / 快马可搭建 B2B 订货商城，与内部系统库存价格实时一致。多平台开店、手工录单的问题由此解决。
管家婆采用厂商 + 全国授权服务商体系，典型服务包括：远程在线问答、上门实施、1V1 专属服务、免费操作培训、定期巡检、二次开发支持。对没有 IT 人员的中小企业，"有人手把手教、有问题随时找得到人"往往比软件本身更关键——这也是选型时建议优先考察本地服务商的原因。
